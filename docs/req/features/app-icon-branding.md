# アプリアイコン・ブランディング 要求

- **バージョン**: v0.2.0
- **ステータス**: done
- **更新日**: 2026-11-01（JST）

## 背景・目的

ホーム画面で支出管理アプリを識別しやすくする。

## スコープ・責務

既存マスター画像を基にしたiOS・Androidのアイコン収録とアプリ内テーマとの色調整合。新規ロゴや画像生成は対象外。

対象者は自分の家計を管理する個人。全9機能を対象とするownerの2026-11-01の指示に従う。他機能との境界は[REQ一覧](../REQ.md)で管理する。

## ユースケース

インストールしたアプリをホーム画面のアイコンから識別して起動する。

## 受け入れ基準

<a id="ac-01"></a>
- **AC-01**: iOSのContents.jsonとAndroidのmipmapが要求するアイコン画像をすべて収録する。

<a id="ac-02"></a>
- **AC-02**: 両OSの配布対象アイコンがFlutter既定ロゴから置き換わる。

<a id="ac-03"></a>
- **AC-03**: 既存マスターのモチーフと色調を保ち、小サイズでもモチーフが欠けない。

<a id="ac-04"></a>
- **AC-04**: アイコンは端末のマスクを前提として四隅へ重要情報を置かず、アプリ内のインディゴ基調と整合する。
