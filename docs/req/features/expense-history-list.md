# 支出履歴・過去一覧 要求

- **バージョン**: v0.3.0
- **ステータス**: done
- **更新日**: 2026-11-01（JST）

## 背景・目的

過去の支出を日付や条件から探し、振り返れるようにする。

## スコープ・責務

指定月または全期間の履歴、タイムライン、月間カレンダー、日別・月別合計、メモ部分一致検索、複数カテゴリ・記録元の絞り込み。明細変更は手動支出機能へ委譲する。

対象者は自分の家計を管理する個人。全9機能を対象とするownerの2026-11-01の指示に従う。他機能との境界は[REQ一覧](../REQ.md)で管理する。

## ユースケース

対象月を選ぶ → 一覧またはカレンダーを選ぶ → キーワード・カテゴリ・記録元で絞り込む → 明細を開く。

## 受け入れ基準

<a id="ac-01"></a>
- **AC-01**: 表示月全体の金額合計と月間合計が一致する。検索時は月間合計と検索結果合計を区別して表示する。

<a id="ac-02"></a>
- **AC-02**: 日別小計とその日の対象明細が一致し、明細は日時降順で表示する。

<a id="ac-03"></a>
- **AC-03**: 期間・キーワード・カテゴリ・記録元をANDで絞り込み、0件時は案内と条件クリアを表示する。

<a id="ac-04"></a>
- **AC-04**: カレンダーの日付を選ぶとその日の明細と小計を表示し、対象月を変更した場合は日付選択を解除する。

<a id="ac-05"></a>
- **AC-05**: キーワードはメモ（店舗名を含む）を対象に英字の大小・全角半角を正規化した部分一致検索とする。

<a id="ac-06"></a>
- **AC-06**: カテゴリ複数選択内はOR、未選択は全カテゴリ。記録元は全件・手動・Apple Payを選べる。

<a id="ac-07"></a>
- **AC-07**: 全期間一覧は50件単位で追加取得し、追加取得で重複・欠落を生じさせない。
