# カテゴリマスター管理 要求

- **バージョン**: v0.3.0
- **ステータス**: done
- **更新日**: 2026-11-01（JST）

## 背景・目的

生活に合わせて分類し、カテゴリ整理で既存支出を失わないようにする。

## スコープ・責務

標準カテゴリの初期登録、追加、名称・アイコン・色の編集、並び替え、安全削除。未分類はシステム予約。

対象者は自分の家計を管理する個人。全9機能を対象とするownerの2026-11-01の指示に従う。他機能との境界は[REQ一覧](../REQ.md)で管理する。

## ユースケース

カテゴリ一覧 → 新規作成または編集 → 並び替え → 不要カテゴリを確認して削除。

## 受け入れ基準

<a id="ac-01"></a>
- **AC-01**: 有効な名称・アイコン・色を保存し、再起動後に復元する。

<a id="ac-02"></a>
- **AC-02**: 並び替えた順序を一覧と支出入力へ反映する。

<a id="ac-03"></a>
- **AC-03**: 使用中カテゴリ削除時に紐づく支出を未分類へ移し、未分類は編集・削除できない。

<a id="ac-04"></a>
- **AC-04**: 名称は前後空白を除いて1〜20文字。空白のみと同名重複を拒否する。

<a id="ac-05"></a>
- **AC-05**: 移し替え・カテゴリ配分削除・カテゴリ削除が一体で成功または取り消され、支出合計は変わらない。

<a id="ac-06"></a>
- **AC-06**: 初回起動で食費・日用品・交通費・カフェ・外食、衣服・美容、医療・健康、趣味・娯楽、住まい・通信・未分類を各1件生成する。
