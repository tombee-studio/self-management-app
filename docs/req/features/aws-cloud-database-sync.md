# クラウドデータアクセス 要求

- **バージョン**: v0.4.0
- **ステータス**: done
- **更新日**: 2026-11-01（JST）

## 背景・目的

AWS APIを通じて支出・カテゴリ・予算を保存・取得し、複数端末から同じ確定データを利用する。

## スコープ・責務

単一所有者の個人利用、組み込み接続先とHTTPS上書き、固定所有者IDの表示、取得・保存・再試行・状態表示、Terraform構成。第三者向け多人数公開サービス、端末内DB、業務データの永続キャッシュ、オフライン保存、同期キューは対象外。機能の識別子とファイル名aws-cloud-database-syncは追跡用に維持し、新機能として分割しない。

## ユースケース

起動してAPI取得 → 入力してAPI保存 → 成功後に一覧を再取得。失敗時は入力を保持し、結果不明の場合は同じ要求IDで確認/再送する。

## 受け入れ基準

<a id="ac-01"></a>
- **AC-01**: 通信失敗時はエラーと再試行を表示し、入力とセッション内の直前表示を保持する。未取得データのオフライン参照・保存は提供しない。

<a id="ac-02"></a>
- **AC-02**: 追加・更新・削除はAWS API確定後に成功とし、同じ要求IDの再送で二重更新しない。応答喪失時は結果不明として確認/再送できる。

<a id="ac-03"></a>
- **AC-03**: 削除済み明細は通常の取得結果に含めず、許可期間内の取り消しで同じID・内容に戻る。

<a id="ac-04"></a>
- **AC-04**: 起動・復帰・明示更新・変更成功後に必要な画面データをAPI取得する。自動同期ON/OFFとPush/Pullは提供しない。

<a id="ac-05"></a>
- **AC-05**: 取得/保存中・成功・失敗・結果不明を区別し、失敗で最終成功日時を更新しない。

<a id="ac-06"></a>
- **AC-06**: 更新競合はサーバーの集約版で検出し、古い版は拒否して入力を保持し最新版の確認を案内する。端末時計で上書き優先度を決めない。

<a id="ac-07"></a>
- **AC-07**: 支出・カテゴリ・カテゴリ配分・予算をAWSに保存し、カテゴリ廃止時の未分類化と配分削除が一体で可視化され、支出合計が変わらない。

<a id="ac-08"></a>
- **AC-08**: 月額500円を運用目標とし、費用通知と計測条件を構成へ記録する。通知は課金停止や上限保証を意味しない。
