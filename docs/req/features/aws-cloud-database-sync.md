# クラウド同期 要求

- **バージョン**: v0.2.0
- **ステータス**: done
- **更新日**: 2026-11-01（JST）

## 背景・目的

ローカル操作を保ちながらクラウドへ支出・カテゴリ・予算を保存し、端末間で整合させる。

## スコープ・責務

単一所有者の個人利用、組み込み接続先、接続先上書き、固定所有者ID、手動・自動同期、削除・取り消し同期、失敗時再送、Terraform構成。第三者向け多人数配布・公開サービス運用は対象外。

対象者は自分の家計を管理する個人。全9機能を対象とするownerの2026-11-01の指示に従う。他機能との境界は[REQ一覧](../REQ.md)で管理する。

## ユースケース

起動・保存・復帰で自動同期 → 設定画面で状態と最終成功日時を確認 → 必要時に手動同期。オフライン操作は次回同期で反映。

## 受け入れ基準

<a id="ac-01"></a>
- **AC-01**: 通信失敗時もローカルの支出を参照・保存できる。

<a id="ac-02"></a>
- **AC-02**: 同期成功後に追加・更新・削除が両側で整合し、失敗した変更は次回に再送する。

<a id="ac-03"></a>
- **AC-03**: 削除済み明細がPullで復活せず、取り消し時は同じIDの通常明細に戻る。

<a id="ac-04"></a>
- **AC-04**: 起動・復帰・変更後に同期する。自動同期OFFでは自動通信を止め、手動同期のみ許可する。

<a id="ac-05"></a>
- **AC-05**: 同期中・成功・失敗・最終成功日時を区別し、失敗では成功日時を更新しない。

<a id="ac-06"></a>
- **AC-06**: 競合は更新日時が新しい変更を優先し、同時刻はサーバー既存値を保持する。未送信のローカル変更は古いPullで上書きしない。

<a id="ac-07"></a>
- **AC-07**: 支出・カテゴリ・カテゴリ別配分・予算を同期し、カテゴリ削除は明細移行と矛盾しない状態を復元できる。

<a id="ac-08"></a>
- **AC-08**: 月額500円を運用目標とし、費用通知と計測条件を構成へ記録する。通知は課金停止や上限保証を意味しない。
