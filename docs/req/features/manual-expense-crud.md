# 支出の手動登録・編集・削除 要求

- **バージョン**: v0.2.0
- **ステータス**: done
- **更新日**: 2026-11-01（JST）

## 背景・目的

日々の支出を記録し、誤記や不要な明細を修正できるようにする。

## スコープ・責務

金額、カテゴリ、日時、支払い方法、任意メモの入力、編集、削除、連続登録、削除取り消し、ローカル永続化。削除のクラウド反映は同期機能の責務。

対象者は自分の家計を管理する個人。全9機能を対象とするownerの2026-11-01の指示に従う。他機能との境界は[REQ一覧](../REQ.md)で管理する。

## ユースケース

支出を追加 → 金額とカテゴリを指定 → 必要に応じて日時・支払い方法・メモを変更 → 保存。既存明細はタップで編集、確認して削除。スワイプ削除は5秒間取り消せる。

## 受け入れ基準

<a id="ac-01"></a>
- **AC-01**: 有効な入力を1件として保存し、再起動後に同じ内容を参照できる。

<a id="ac-02"></a>
- **AC-02**: 編集・削除を一覧と集計へ反映し、削除をキャンセルした場合は明細を保持する。

<a id="ac-03"></a>
- **AC-03**: 不正な入力を保存せず、明示削除の確認と保存失敗時の案内を表示する。

<a id="ac-04"></a>
- **AC-04**: 金額は日本円の整数1〜99,999,999円。0・負数・上限超過・不正な計算結果は保存しない。

<a id="ac-05"></a>
- **AC-05**: カテゴリは存在するIDを必須とし、初期選択は未分類。日時は1970-01-01以降で未来日を許可する。

<a id="ac-06"></a>
- **AC-06**: メモは任意で100文字以内。前後空白を除去し、改行を空白へ置換する。支払い方法は現金・Apple Pay・カード・電子マネー・その他から選ぶ。

<a id="ac-07"></a>
- **AC-07**: 連続登録後に金額とメモを空にし、日付・カテゴリ・支払い方法は保持する。

<a id="ac-08"></a>
- **AC-08**: スワイプ削除は直ちに表示へ反映し、5秒以内の元に戻すで元のID・内容を復元する。明示削除には取り消しを付けない。

<a id="ac-09"></a>
- **AC-09**: 入力を変更した状態で閉じる場合は破棄確認し、保存失敗時は入力内容を保持する。
