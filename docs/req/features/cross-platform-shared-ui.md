# 共通UI・マルチデバイス対応 要求

- **バージョン**: v0.2.0
- **ステータス**: done
- **更新日**: 2026-11-01（JST）

## 背景・目的

スマートフォン・タブレット間で一貫した主要操作を提供する。

## スコープ・責務

iOS 16以降・Android 12以降の共通Flutter画面、日本語、縦横回転、セーフエリア、入力中キーボード対応、画面幅によるナビゲーション・フォームの適応。最低OS版はiOS 16・Android 12とし、ビルド設定もこれに揃える。

対象者は自分の家計を管理する個人。全9機能を対象とするownerの2026-11-01の指示に従う。他機能との境界は[REQ一覧](../REQ.md)で管理する。

## ユースケース

今日・履歴・予算・カテゴリを操作し、画面を回転・リサイズしながら入力・確認する。

## 受け入れ基準

<a id="ac-01"></a>
- **AC-01**: 幅320・600・900論理ピクセルの代表画面で主要操作をスクロール等により利用できる。

<a id="ac-02"></a>
- **AC-02**: 回転・リサイズで選択日・表示月・入力内容を失わない。

<a id="ac-03"></a>
- **AC-03**: iOS・Androidで同じ業務操作・表示内容を提供する。

<a id="ac-04"></a>
- **AC-04**: ナビゲーションは幅600未満で下部タブ、600以上840未満でNavigationRail、840以上でラベル付きサイドナビと2ペイン。新規フォームは600未満でBottomSheet、600以上で中央ダイアログ。840以上の既存明細編集は右ペイン内で行う。

<a id="ac-05"></a>
- **AC-05**: SafeAreaとキーボード領域を避け、入力完了・背景・タブ操作でフォーカスを解除する。

<a id="ac-06"></a>
- **AC-06**: 画面幅は向き名ではなく現在の論理ピクセル幅で判定する。840以上の日次画面は左にサマリー、右に明細・編集を表示し、⌘N・⌘←/→・Escで追加・日付移動・閉じるを操作できる。
