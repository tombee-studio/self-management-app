# 日次支出ダッシュボード 要求

- **バージョン**: v0.2.0
- **ステータス**: done
- **更新日**: 2026-11-01（JST）

## 背景・目的

選択日の支出総額・カテゴリ内訳・明細を把握し、使いすぎに気付けるようにする。

## スコープ・責務

日付移動、日次合計、カテゴリ内訳、明細、登録・編集への導線。日次目安は予算機能の計算結果を参照する。

対象者は自分の家計を管理する個人。全9機能を対象とするownerの2026-11-01の指示に従う。他機能との境界は[REQ一覧](../REQ.md)で管理する。

## ユースケース

今日画面を開く → 前日・翌日または日付を選ぶ → 合計・内訳・明細を確認 → 明細編集または支出追加。

## 受け入れ基準

<a id="ac-01"></a>
- **AC-01**: 選択日の対象明細の金額合計と日次合計が一致する。

<a id="ac-02"></a>
- **AC-02**: 対象明細が0件の日は合計0円と空状態を表示する。

<a id="ac-03"></a>
- **AC-03**: 登録・編集・削除後、再起動や画面移動をせず合計・内訳・明細へ反映する。

<a id="ac-04"></a>
- **AC-04**: 日付は端末ローカル時間で区切り、日界直前・直後の明細を別日に計上する。

<a id="ac-05"></a>
- **AC-05**: カテゴリ別金額の合計は日次合計と一致し、合計0円では割合計算による例外を発生させない。

<a id="ac-06"></a>
- **AC-06**: データ取得失敗時にエラーと再試行を表示する。
