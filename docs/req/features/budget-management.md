# 予算設定・管理 要求

- **バージョン**: v0.3.0
- **ステータス**: done
- **更新日**: 2026-11-01（JST）

## 背景・目的

設定した家計期間の残予算・日次目安・支出ペースを把握する。

## スコープ・責務

月間総予算、開始日、カテゴリ配分、残額・日次目安・着地予測、通知、キーボードと保存後遷移。暦月の履歴集計とは別の期間を扱う。

対象者は自分の家計を管理する個人。全9機能を対象とするownerの2026-11-01の指示に従う。他機能との境界は[REQ一覧](../REQ.md)で管理する。

## ユースケース

予算画面で金額・開始日・配分・通知を設定 → 保存 → 元画面または今日へ戻り、残額と目安を確認。

## 受け入れ基準

<a id="ac-01"></a>
- **AC-01**: 有効な予算設定を保存し、再起動・再表示後も復元する。

<a id="ac-02"></a>
- **AC-02**: 開始日〜翌月開始日前日を1期間とし、その期間の実績から残額・日次目安を計算する。

<a id="ac-03"></a>
- **AC-03**: 背景タップ・完了操作でキーボードを閉じ、保存成功後は元画面または今日へ戻る。保存失敗時は遷移しない。

<a id="ac-04"></a>
- **AC-04**: 月間総予算は1〜99,999,999円、開始日は1〜28。カテゴリ別配分は0〜99,999,999円とし、総額超過は警告して保存を許可する。

<a id="ac-05"></a>
- **AC-05**: 残額は予算−期間実績、日次目安はmax(0,floor(残額÷当日を含む残り暦日数))とする。

<a id="ac-06"></a>
- **AC-06**: 着地予測はfloor(期間実績÷当日を含む経過暦日数×期間総暦日数)。最初の3日間は予測警告を表示しない。

<a id="ac-07"></a>
- **AC-07**: 通知有効時に期間内で80%到達・100%到達を各1回通知し、通知拒否時も記録・集計を継続する。
