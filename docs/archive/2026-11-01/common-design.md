#### 1. アプリケーション概要
- **プロダクト名**: 支出管理アプリ (iris-app)
- **目的**: 日常の支出を素早く記録・可視化し、予算管理と支出傾向の分析を支援する。

---


#### 4. 全体仕様・共通要件
- **開発フレームワーク**: **Flutter** (Dart) - 全プラットフォームで単一コードベースUIを実現
- **対象プラットフォーム**:
  - **Primary**: iOS 16.0 以降（iPhone / iPad）
  - **Secondary (拡張予定)**: Android 12.0 以降（スマートフォン / タブレット）
- **対応フォームファクタ＆画面の向き**:
  - スマートフォン（縦向き Portrait / 横向き Landscape）
  - タブレット（縦向き Portrait / 横向き Landscape、2ペイン対応）
- **対応言語**: 日本語
- **データ保存・クラウド外在化**:
  - **ローカルファースト＋AWSクラウド外在化**: 端末内SQLite（drift）でオフライン即時保存を担保しつつ、TerraformでプロビジョニングされたAWS上の完全サーバーレスDB（DynamoDB + HTTP API + Lambda）へ自動差分同期。月額運用コストは500円以内（実質0〜20円/月）を厳格に維持。
- **インフラ管理 (IaC)**: Terraform によるAWS全リソース（DynamoDB, API Gateway, Lambda, IAM, Budgets）のコード管理・自動構築。
- **共通バリデーション**:
  - 金額: 0円以上の数値
  - 日付: 有効な日付形式

## 移行元: docs/IMPLEMENTATION.md

#### 1. 全体アーキテクチャ方針
- **開発フレームワーク**: **Flutter (Dart)**（レンダリングエンジン: Impeller）
- **設計方針**: レイヤードアーキテクチャ・フィーチャー指向（Feature-first）・テスタビリティ重視
- **UI共通化方針**: iOS（iPhone/iPad）および Android の全画面・全ウィジェットを 100% 共通の Dart コードで実装。ネイティブ差異は `MethodChannel` / プラットフォーム抽象化層に完全に隠蔽。
- **アダプティブUI方針**: ウィンドウサイズクラス（Compact, Medium, Expanded）に基づくレスポンシブ適応（スマホ横向き、タブレット横向き2ペイン、セーフエリア自動考慮）
- **状態管理＆ローカル永続化**: Riverpod / StateNotifier による状態管理、SQLite (drift) による**完全ローカル端末内永続化**（外部サーバー通信なし、プライバシー最優先・完全オフライン動作）。

---


#### 3. 共通モジュール・データ永続化設計 (Local Database & AWS Sync)

##### 3.1 ローカルDB選定と方針
- **ORM / ライブラリ**: **`drift` (SQLite)** を採用（型安全、リアクティブなクエリStream購読、マイグレーション支援）。
- **保存先**: 各OSのサンドボックス化されたローカルアプリデータ領域（オフラインキャッシュとして活用）。

##### 3.2 コアテーブルスキーマ (drift)
- `categories`: カテゴリID、名称、アイコン名、カラーHEX、表示順、`updated_at`, `is_synced`, `is_deleted`
- `expenses`: 支出ID、金額、カテゴリID(FK)、店舗名/メモ、決済日時(`spent_at`)、決済手段詳細、外部取引ID(`external_tx_id` - ユニーク制約/インデックス)、登録日時、`updated_at`, `is_synced`, `is_deleted`
- `budgets`: 目標日次/月次予算設定、`updated_at`, `is_synced`

##### 3.3 AWS クラウド外在化・完全サーバーレス同期設計 (月500円以内)
- **インフラ構成 (Terraform IaC)**: `terraform/` 配下に完全コード化。
- **DB選定**: **Amazon DynamoDB**（オンデマンド従量課金、常時無料枠 25GB/25WCU/25RCU 内で運用）。
- **API層**: **Amazon API Gateway (HTTP API v2)** ＋ **AWS Lambda (Node.js 20.x)**（常時無料枠 100万回/月）。
- **運用コスト想定**: 個人・小規模利用で月額約 **0円〜20円 (実質 $0.00〜$0.15)**。月々500円の予算枠を厳格にクリア。
- **コスト防壁**: AWS Budgets で月額 $2.00 超過時にメール通知する安全装置を配備。
